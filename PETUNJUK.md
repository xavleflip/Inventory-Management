# Petunjuk SasaStok

Dokumentasi utama telah dihimpun di [README.md](README.md), mencakup:

- Tautan hosting dan cara menjalankan aplikasi lokal.
- Akun awal, login, logout, dan pengubahan kata sandi.
- Hak akses pemilik usaha dan karyawan.
- Panduan Ringkasan, Bahan baku, Transaksi, Penyesuaian stok, Laporan & riwayat, dan Kelola pengguna.
- Filter, ekspor CSV, aturan perhitungan, serta validasi stok.
- Penyimpanan browser, sesi, keterbatasan keamanan, dan penyelesaian masalah.
- Riwayat perubahan dan hasil verifikasi.

Mulai pembaruan 16 November 2026, antarmuka menggunakan nama **SasaStok**. Tombol pengisian akun demo dan reset data tidak lagi tersedia. Tombol **Bersihkan filter** pada laporan hanya membersihkan filter.

Panduan versi sebelumnya yang menyebut reset data demo bersifat historis. Ikuti README untuk penggunaan versi saat ini.

Pembaruan 20 November 2026: tekan kartu Ringkasan untuk melihat rincian. Saat menambah bahan, kode dibuat otomatis; isi nama, satuan, Persediaan awal, dan minimum. Panduan lengkap tersedia pada README.
